# TT Memory Mobile UI

React Native/Expo implementation of the TT Memory design shown in the generated UI concept.

## Run
```bash
npm install
npx expo start
```

Included: onboarding, register, login, home, memories, add memory, family, stories, vault, legacy, profile/settings. Demo image data is used for the visual prototype.

Next: connect these screens to the FastAPI + MySQL + Cloudflare R2 backend already created.
